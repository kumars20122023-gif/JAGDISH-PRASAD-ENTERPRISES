Online Database Sync सेटअप

नीचे Firebase Web App config पेस्ट करें। यह config Firebase Console → Project settings → Your apps → Web app से मिलता है।

Firebase सेटअप होने तक यह ब्राउज़र Local mode में काम करता है।

Firebase सुरक्षा नियम

Firebase Console → Firestore Database → Rules में नीचे दिए गए नियम प्रकाशित करें। ऐप में सार्वजनिक Signup नहीं है; Firebase Authentication में उपयोगकर्ता को स्वयं Console से बनाएं।

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /shops/jp-general-store/{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
यह नियम authenticated users को इस दुकान के डेटा तक access देता है। Firebase Authentication में केवल अपने भरोसेमंद उपयोगकर्ता बनाएं। अपना पासवर्ड किसी के साथ साझा न करें।

महत्वपूर्ण जानकारी

Local mode में डेटा उसी डिवाइस/ब्राउज़र में सेव रहता है। दोनों डिवाइस पर एक जैसा डेटा देखने के लिए Firebase config और एक ही Firebase login से सफलतापूर्वक Connect करना जरूरी है। GST Invoice जारी करने से पहले अपना GSTIN, सही HSN/SAC और लागू GST दरें जोड़ें/जांचें। यह ऐप GST compliance की कानूनी पुष्टि नहीं करता।
